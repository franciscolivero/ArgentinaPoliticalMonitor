Sources & methodology

  • EncuestAR — poll aggregator. The Milei–Kicillof runoff chart (Chart 01) is refreshed daily from EncuestAR, which relays and dates head-to-head ballotage polls published by third-party firms (Tendencias, CB, Trends, Opinaia, RDT, Proyección, Isasi-Burdman, Explanans and others). Each poll belongs to the firm that ran it; the aggregation is EncuestAR's, reused with attribution. Only complete-ficha ballotage polls enter the smoothed average; polls the aggregator flags as incomplete are shown as dots but held out of the line.
  • EncuestAR — national vote by space. Charts 02–03 are refreshed daily from EncuestAR's vote-by-space race, which normalises each firm's poll into seven political spaces. The dots are individual polls on their fieldwork-end date; the lines are our kernel-smoothed averages. The "Alianza LLA+PRO" line is EncuestAR's day-by-day sum of the LLA and PRO averages — a sum, not a measured coalition — so it reads as a ceiling.
  • Presidential approval (Chart 04). National aprobación de gestión polls from ESPOP (UdeSA), AtlasIntel, Poliarquía, Management & Fit, QSocial, Zuban Córdoba, Synopsis, Alaska + Trespuntozero and Delfos, compiled from each firm’s published results and press coverage (every row in approval_polls.csv carries its source link). Favourability (imagen) readings are a different question and are excluded. The average follows the Silver Bulletin polling-average methodology: sample-size weights with diminishing returns and a per-firm cap so no pollster floods the average; local-linear regression blending a short and a long bandwidth, both chosen by how well they predict the next poll; house effects estimated separately for approve and disapprove, shrunk by each firm’s total sample and iterated to convergence; and a band calibrated so 90% of out-of-sample polls fall inside it. Argentine firms have no public accuracy rating, so every pollster starts at the same rating (editable in build_approval.py). Where a poll’s exact fieldwork date was not published it is placed mid-month and marked ≈ on hover.
  • ICG — Universidad Torcuato Di Tella. Monthly Índice de Confianza en el Gobierno (0–5), fieldwork by Poliarquía. monthly reports
  • Polymarket — Argentina Presidential Election Winner. Live market-implied probabilities via the public Polymarket Gamma API. Prediction-market prices are money-weighted trader expectations, not survey estimates, and this market is relatively thin (low six-figure volume), so treat moves with caution.
Read-with-care notes. The runoff series mixes firms with very different house effects, which is exactly why the average is kernel-smoothed rather than drawn point-to-point: a single house (e.g. an outlying Delfos or Arena Pública reading) cannot swing the line on its own. It measures a hypothetical Milei–Kicillof ballotage, not a first-round multi-candidate ballot. No values are interpolated or invented; gaps are left as gaps.

Updating monthly

Two ways to refresh, both in the package:

  • Run python update_data.py. It re-fetches the Di Tella ICG page automatically, rewrites data.json, and re-embeds the data block in this HTML between the DATA_START / DATA_END markers.
  • Or edit the data.json arrays by hand and re-run the embed step. Each new point only needs a date, value and firm.
  • The Milei–Kicillof runoff chart (Chart 01) updates on its own: fetch_encuestar.py runs daily via GitHub Actions, scrapes the EncuestAR ballotage rows, and commits encuestas_history.json, which the page reads on load. Run it by hand anytime with python fetch_encuestar.py. The embedded headToHead2026 block is only an offline fallback.
  • The vote-by-space charts (Charts 02–03) update the same way: fetch_encuestar_espacio.py runs daily via GitHub Actions and commits espacio_history.json, which the page reads on load. Run it by hand with python fetch_encuestar_espacio.py (or --list-espacios to inspect what it parsed). The embedded espaciodata block is only an offline fallback.
  • The approval chart (Chart 04) updates on its own: update-approval.yml runs daily, fetch_approval.py pulls any new aprobación de gestión polls from EncuestAR into approval_polls.csv, and build_approval.py recomputes the average into approval_history.json, which the page reads on load. Hand-entered rows always take precedence over scraped ones, so polls EncuestAR does not carry can still be added to the CSV by hand; the Action rebuilds on every CSV change. Scraped rows are tagged origin=encuestar.
  • For the by-president chart, just drop the new Evolution_ICG.xlsx into the repository root each month — the page reads it on load, no rebuild needed. The embedded copy here is a fallback for offline viewing.
