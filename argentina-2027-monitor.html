Sources & methodology

  • ESPOP / LOOP — Universidad de San Andrés (UdeSA). Bimonthly-to-monthly satisfaction and opinion survey; supplies Milei approval, personal image and leaders’ image. espop page
  • Polling firms (Empresa Encuestadora). Head-to-head and first-round voting-intention figures are attributed to the pollster that published each poll: CB Consultora (9–13 Dec 2025), Isasi-Burdman (19–27 Nov 2025) and Opina Argentina (30 Jun–2 Jul 2025).
  • ICG — Universidad Torcuato Di Tella. Monthly Índice de Confianza en el Gobierno (0–5), fieldwork by Poliarquía. monthly reports
  • ICG by president (Evolution_ICG.xlsx). Cross-administration ICG re-indexed by months in office, sourced from the same Di Tella series. The page reads this spreadsheet live from the repository.
  • Polymarket — Argentina Presidential Election Winner. Live market-implied probabilities via the public Polymarket Gamma API. Prediction-market prices are money-weighted trader expectations, not survey estimates, and this market is relatively thin (low six-figure volume), so treat moves with caution.
Read-with-care notes. ESPOP measures government-management approval and a separate personal positive-image score — they are related but not identical, and are plotted as distinct lines. The head-to-head series is sparse and mixes firms with very different house effects. Bullrich, Massa and Grabois were not offered as options in the latest voting-intention poll, so they appear only where a sourced figure exists (Bullrich via the ESPOP image panel). No values are interpolated or invented; gaps are left as gaps.

Updating monthly

Two ways to refresh, both in the package:

  • Run python update_data.py. It re-fetches the Di Tella ICG page and the published-poll table automatically, lets you paste the new ESPOP figures, rewrites data.json, and re-embeds the data block in this HTML between the DATA_START / DATA_END markers.
  • Or edit the data.json arrays by hand and re-run the embed step. Each new point only needs a date, value and firm.
  • For the by-president chart, just drop the new Evolution_ICG.xlsx into the repository root each month — the page reads it on load, no rebuild needed. The embedded copy here is a fallback for offline viewing.
