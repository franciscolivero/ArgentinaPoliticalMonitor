Rating table

Weight is what the monitor’s averages use: rated firms average 1.0, and firms with no election-eve track record are left at 1.0. House lean is the firm’s tilt toward (+) or against (−) the Peronist candidate after removing the industry-wide miss. A grade marked “prov.” rests on a single contest.

Method

  1. Polls. For each national contest (PASO, general, runoff), the last poll each firm published with fieldwork ending within 28 days of the vote. Compiled from the Spanish- and English-language Wikipedia poll tables, which cite the original releases. Some 2015 and 2019 entries carry publication rather than fieldwork dates.
  2. Comparable shares. Poll and result are both re-expressed as shares of the major candidates only (three in first rounds, two in runoffs), which removes undecided, blank and minor-candidate columns that firms report inconsistently.
  3. Error. Error on the margin between the candidates who actually finished first and second. Negative means the firm underestimated the winner’s lead.
  4. Relative error. Each poll’s absolute error minus the average absolute error of the other firms in the same contest.
  5. Shrinkage. A firm’s score is its average relative error multiplied by n / (n + k), with k = — estimated from the data (how noisy one contest is versus how much firms genuinely differ). One lucky contest cannot buy a top grade.
  6. Grade and outlook. AAA ≤ −3 pts, AA ≤ −2, A ≤ −1, BBB+ ≤ −0.33, BBB ≤ +0.33, BBB− ≤ +1, BB ≤ +2, B ≤ +3.5, CCC above. Outlook is the direction the most recent contest moved the score.
  7. Weight. Proportional to (market error ÷ firm’s expected error)², rescaled to average 1.0 and bounded between 0.5 and 1.6. The approval average on the main monitor uses these weights.

Rebuilt by build_pollster_ratings.py from pollster_elections.csv, pollster_polls.csv and pollster_aliases.csv. Add a new election by appending rows to the two CSVs; the GitHub Action recomputes everything.

Ratings measure public election-eve vote-intention polls only. A firm’s private work for clients, or its accuracy in provincial races, is not captured here.
