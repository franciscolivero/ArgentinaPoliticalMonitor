Interprovincial ranking of governors — positive image

The 24 provincial governors ranked by positive image, from CB Global Data’s monthly federal survey (page 8 of the report). Bars show positive / negative / don’t-know shares; the marker at right is the month-over-month change in positive image. This page reads Governors_CB.xlsx from the repository, so replacing that file each month updates it automatically.

Source & methodology

  • CB Global Data — Ranking interprovincial de gobernadores. Monthly federal survey of positive image for the 24 provincial executives (23 provinces + CABA).

Updating monthly: open the CB report (page 8), transcribe each governor’s positive / negative / NA shares and the previous-month value into Governors_CB.xlsx, keep it sorted by positive image, save it under the same name and upload it to the repository root. No rebuild needed.

Prediction-market and polling charts live on the main monitor. Image ratings are point estimates with sampling error; treat small month-to-month moves as noise.
