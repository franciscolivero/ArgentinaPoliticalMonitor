Does the ICG predict incumbent survival? Five elections say: mostly

Each dot is a presidential election where the sitting coalition ran: the government’s ICG in the election window (Aug–Oct average) against whether it kept the presidency. The curve is a ridge-penalised logistic fit to those five races; the purple line is the current government’s ICG. Note the sobering pair: 2007 won at ICG 1.92, but 2019 lost at 2.04 — the middle of the curve is genuinely uncertain, and the model says so.

Where the forecast really lives

It hinges on the runoff transfer, not on poll noise

The blended probability is nearly flat in polling uncertainty but swings hard with the runoff-transfer assumption. The forecast is, above all, a judgment about how the rest of the field splits in a Milei–Kicillof runoff.

Track record · month by month

How this forecast evolves as new data lands

Every month, the model’s default-settings output is committed to the repository (forecast_history.json) and a point is added here — the polls read, the fundamentals read, and the blend. The hollow marker is this month’s live provisional value (not yet committed). One point today; a track record by 2027.

What this is, and what it isn’t. The fundamentals side is a logistic regression trained on real outcomes — but on the only five observations history provides, so it is ridge-penalised and its middle range is honestly uncertain. The polls side is a transparent simulation, not a fitted model. The blend weight is a judgment call you control. Treat the band and the disagreement between the two reads — not the headline decimal — as the finding.

Method & sources

  • Fundamentals (trained 2003–2023). For each presidential election with an incumbent coalition running (2007, 2011, 2015, 2019, 2023), the government’s ICG (UTDT, election-window Aug–Oct average from the same series as the monitor’s Chart 05): 1.92, 2.50, 1.87, 2.04, 1.17 — outcomes won, won, lost, lost, lost. Ridge-penalised logistic: P(win)=σ(−2.08+0.87·ICG). At the current ICG this gives ≈43%.
  • Polls Monte Carlo. First-round intentions perturbed with Student-t(5) shocks scaled to the chosen uncertainty (2023 calibration: late-poll RMSE ≈3.3 pts first round, 3.8 runoff); runoff decided by the transfer rate (drawn with ±8 pts of its own noise). Win = first round (≥45%, or ≥40% with a 10-pt lead) or runoff >50%. 20,000 draws per update.
  • Runoff transfer anchor. Incumbent capture of the residual vote: 22.8% in 2023, 40.3% in 2015. A two-point ICG line suggests ≈45% at today’s ICG, but that extrapolates beyond anything observed, so the default is capped at the 40% maximum.
  • Blend. P = w·P(polls) + (1−w)·P(fundamentals), default w = 0.55 at ~16 months out.
  • Monthly tracking. update_forecast.py recomputes the default-settings forecast from the repo’s current data and appends it to forecast_history.json; run it with the monthly update and commit both.

A scenario tool with a memory, not a prediction machine. Built by Francisco Olivero; polling and market data on the main monitor.
